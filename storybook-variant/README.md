# ChessEngineered Variant A - Storybook

Material separado desde el prototipo `ChessEngineered Branding.html`.

## Contenido

- `index.html`: entrada independiente para revisar solo la variante Storybook.
- `src/storybook.jsx`: pantallas Storybook de repertorio, entrenamiento y mobile.
- `src/primitives.jsx`: logo, Pawny, burbujas y atomos compartidos usados por Storybook.
- `src/board.jsx`: tablero usado por la pantalla de entrenamiento.
- `assets/`: imagenes de Pawny necesarias para renderizar la variante.

## Uso

Abrir `index.html` en el navegador. Requiere internet para cargar React, Babel y Google Fonts desde CDN.
